## 🎉 **NEUE FEATURES IN v1.1.0:**

### **1. ⚡ WiFi TX Power Einstellbar**
- **Default:** 8.5 dBm (34 in 0.25 dBm units)
- **Range:** 2.0 - 21.0 dBm
- **UI:** Slider im "Secrets" Tab
- **Gespeichert in:** NVS (persistent)

### **2. 💡 LED Indicator**
- **GPIO:** 8 (ESP32-C3 Super Mini)
- **Logic:** Active LOW (LOW = LED an, HIGH = LED aus)
- **Status:** LED leuchtet während WiFi AP läuft
- **Auto:** LED geht aus wenn WiFi AP stoppt

### **3. ⏱️ Button Hold Time**
- **Vorher:** 1 Sekunde
- **Neu:** 2 Sekunden
- **Zweck:** Verhindert versehentliches Triggern

### **4. ⏲️ WiFi AP Timeout**
- **Vorher:** 3 Minuten
- **Neu:** 5 Minuten
- **Zweck:** Mehr Zeit für Konfiguration

### **5. 🔐 Secrets Tab (4. Tab)**
- **WiFi SSID:** Einstellbar (default: "PGPemu-Setup")
- **WiFi Password:** Einstellbar (default: "PogoPogo")
- **WiFi Security:** WPA2-PSK (wenn Passwort gesetzt)
- **TX Power:** Slider 2.0 - 21.0 dBm
- **Gespeichert:** NVS (persistent über Reboots)

### **6. 🔒 WPA2 Password**
- **Default:** "PogoPogo"
- **Security:** WPA2-PSK
- **Optional:** Leer lassen für Open Network
- **Änderbar:** Über Secrets Tab

## 🔧 **TECHNISCHE DETAILS:**

### **TX Power Berechnung:**
```
Wert in Code: int8_t (8 bis 84)
Wert in dBm = Code * 0.25

Beispiele:
  8  * 0.25 = 2.0 dBm   (Minimum)
 34  * 0.25 = 8.5 dBm   (Default)
 84  * 0.25 = 21.0 dBm  (Maximum)
```

### **LED Logic (Active LOW):**
```c
// ESP32-C3 Super Mini Blue LED
GPIO 8, Active LOW:
  gpio_set_level(LED_GPIO, 0)  → LED AN
  gpio_set_level(LED_GPIO, 1)  → LED AUS
  
// Während WiFi AP läuft:
wifi_ap_manager_start() → led_on()  → GPIO 8 = LOW  → LED leuchtet
wifi_ap_manager_stop()  → led_off() → GPIO 8 = HIGH → LED aus
```

### **NVS Storage:**
```c
Namespace: "wifi_ap"
Keys:
  - "ssid"      (string, max 32 chars)
  - "password"  (string, max 64 chars)
  - "tx_power"  (int8_t, 8-84)

// Gespeichert bei:
wifi_ap_manager_set_config(...)

// Geladen bei:
wifi_ap_manager_init()
```

### **WPA2 Security:**
```c
if (strlen(password) > 0) {
    authmode = WIFI_AUTH_WPA2_PSK;  // Secure
} else {
    authmode = WIFI_AUTH_OPEN;      // Open
}
```
