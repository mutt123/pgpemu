## 🎉 **NEUE FEATURES IN v1.2.0:**

### **🎮 Device Config Tab (5. Tab)**

Komplette PGP Device-Konfiguration über Web-Interface:

1. **PGP_CLONE_NAME** - Device Name
   - Was: Advertised Bluetooth device name
   - Default: "Pokemon GO Plus"
   - Max: 63 characters
   - Beispiel: "My Custom PGP"

2. **PGP_MAC** - MAC Address
   - Was: Bluetooth MAC Address
   - Format: `XX:XX:XX:XX:XX:XX`
   - Default: "00:00:00:00:00:00"
   - Validation: Automatisch

3. **PGP_BLOB** - Blob Data
   - Was: Device-specific blob data
   - Format: Hex string (0-9, A-F)
   - Max: 256 characters
   - Validation: Nur hex erlaubt

4. **PGP_DEVICE_KEY** - Device Key
   - Was: Encryption/Device key
   - Format: Hex string (0-9, A-F)
   - Max: 32 characters
   - Validation: Nur hex erlaubt

## 🎯 **FEATURES:**

### **Web Interface:**

```html
Tab 5: Device Config
├─ Warning Box (Advanced Settings)
├─ Device Name Input
│  └─ Max 63 chars
├─ MAC Address Input
│  └─ Format: XX:XX:XX:XX:XX:XX
├─ Blob Data Textarea
│  └─ Hex string, 256 chars max
├─ Device Key Input
│  └─ Hex string, 32 chars max
├─ Save Button
└─ Reset to Defaults Button
```

### **Input Validation:**

**Frontend (JavaScript):**
- MAC: Regex pattern `[0-9A-Fa-f:]{17}`
- Blob: Regex pattern `[0-9A-Fa-f]*`
- Key: Regex pattern `[0-9A-Fa-f]{0,32}`
- Real-time error messages

**Backend (C):**
- `validate_mac_address()` - Full format check
- `validate_hex_string()` - Character validation
- Error returns on invalid input

### **NVS Storage:**

```
Namespace: "device_cfg"
Keys:
  - "name"  (string, max 64 bytes)
  - "mac"   (string, max 18 bytes)
  - "blob"  (string, max 257 bytes)
  - "dkey"  (string, max 33 bytes)
```

## 📊 **API ENDPOINTS:**

### **1. GET /api/device_config**

**Response:**
```json
{
  "name": "Pokemon GO Plus",
  "mac": "AA:BB:CC:DD:EE:FF",
  "blob": "0123456789ABCDEF",
  "dkey": "FEDCBA9876543210"
}
```

### **2. POST /api/device_config**

**Request:**
```json
{
  "name": "My Custom PGP",
  "mac": "11:22:33:44:55:66",
  "blob": "AABBCCDDEEFF00112233",
  "dkey": "0011223344556677"
}
```

**Response:**
```json
{
  "status": "ok",
  "message": "Device config saved. Restart to apply."
}
```

**Error Response:**
```json
{
  "status": "error",
  "message": "Invalid MAC address format"
}
```

### **3. POST /api/device_config/reset**

**Response:**
```json
{
  "status": "ok",
  "message": "Device config reset to defaults"
}
```

## 💡 **TIPPS:**

### **MAC Address:**
```
Gültig:
  ✅ AA:BB:CC:DD:EE:FF
  ✅ 00:11:22:33:44:55
  ✅ FF:FF:FF:FF:FF:FF

Ungültig:
  ❌ AABBCCDDEEFF (keine Colons)
  ❌ AA-BB-CC-DD-EE-FF (Dashes statt Colons)
  ❌ AA:BB:CC:DD:EE (zu kurz)
```

### **Hex Strings:**
```
Gültig:
  ✅ 0123456789ABCDEF
  ✅ abcdef (lowercase ok)
  ✅ "" (leer ok)

Ungültig:
  ❌ GHIJKLMNOP (keine hex chars)
  ❌ 0x123 (kein 0x prefix)
  ❌ 12 34 56 (keine Spaces)
```
