## 2️⃣ **pgpemu.c - Initialization**

**Location:** `pgpemu-esp32/main/pgpemu.c`  
**Function:** `app_main()`  
**Line:** VOR `wifi_ap_manager_init()` aber NACH NVS init

**HINZUFÜGEN:**
```c
    // Initialize device configuration
    ESP_LOGI(TAG, "Initializing device configuration...");
    device_config_init();
```

**Vollständiges Beispiel:**
```c
void app_main(void)
{
    // ... existing code (NVS init, etc.) ...
    
    // Initialize device configuration
    ESP_LOGI(TAG, "Initializing device configuration...");
    device_config_init();                // NEU!
    
    // Initialize WiFi AP Manager
    ESP_LOGI(TAG, "Initializing WiFi AP Manager...");
    wifi_ap_manager_init();
    
    // ... rest of code ...
}
```

## 3️⃣ **CMakeLists.txt - Source File**

**Location:** `pgpemu-esp32/main/CMakeLists.txt`  
**Section:** `SRCS` Liste

**HINZUFÜGEN:**
```cmake
"device_config.c"
```

**Vollständiges Beispiel:**
```cmake
idf_component_register(
    SRCS 
        "pgpemu.c"
        "button_input.c"
        "wifi_ap_manager.c"
        "web_server.c"
        "stats.c"
        "device_config.c"        # NEU!
        # ... andere Dateien ...
    
    INCLUDE_DIRS "."
)
```

**WICHTIG:** Vergiss das Komma nicht, wenn es vorher keines gab!

## 🐛 **TROUBLESHOOTING:**

### **Build Fehler: "No such file"**
```
device_config.h: No such file or directory
```
**Lösung:** Datei nicht kopiert
```cmd
copy device_config.h pgpemu-esp32\main\
copy device_config.c pgpemu-esp32\main\
```

### **Build Fehler: "undefined reference"**
```
undefined reference to `device_config_init'
```
**Lösung:** CMakeLists.txt fehlt
```cmake
# In CMakeLists.txt SRCS hinzufügen:
"device_config.c"
```

### **Compiler Warnung: "implicit declaration"**
```
implicit declaration of function 'device_config_init'
```
**Lösung:** Include fehlt
```c
// In pgpemu.c:
#include "device_config.h"
```

### **Runtime: Tab nicht sichtbar**
```
Nur 4 Tabs statt 5
```
**Lösung:** web_server.c nicht gepatcht
- Siehe web_server_v1.2.0_PATCH.md
- 5. Tab HTML fehlt

### **Runtime: API Error 404**
```
Failed to load device config
```
**Lösung:** API Handlers nicht registriert
- Siehe web_server_v1.2.0_PATCH.md
- URI Registration fehlt
